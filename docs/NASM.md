# NASM Assembly Rebuild

## Overview

The 16-bit MS-DOS assembly code for Captain Comic II: Fractured Reality has been reverse engineered into fully compilable NASM assembly with purpose annotations for all 182 original functions.

## Key Technical Details

1. Exact parity and byte-level fidelity:
   - Code segment: `comic2_code.bin` is 54,736 bytes, matching the original binary segment byte-for-byte in size and alignment.
   - Relocation table: all 30 DOS relocations were mapped and resolved using named segment constants:
     - `SEG_DATA` (`0x24fe`): main game variables, strings, keyboard layouts, and save game slots (`GAME.000`–`GAME.003`)
     - `SEG_STACK` (`0x160a`): runtime stack segment
     - `SEG_PALETTE` (`0x2206`): EGA 16-color palette registers
     - `SEG_SCRATCH` (`0x0d5d`): PackBits RLE decompression buffer and collision scratchpad
     - `SEG_BUFFER_1` through `SEG_BUFFER_4` (`0x2fcc`, `0x37cc`, `0x3fcc`, `0x47cc`): four EGA planar sprite buffers
   - Executable output: `comic2.exe` is 196,288 bytes, exactly matching `unpacked.exe`.

2. Function annotations:
   - Every function includes a documentation block with category classification, purpose description, and register conventions:

```asm
; ----------------------------------------------------------------------------
; FUNCTION: snd_api_int03  [Audio / API]
; ADDRESS:  1000:08c7
; PURPOSE:  Sound Engine API dispatcher hooked to INT 03h. Accepts commands:
;           AL=0 (stop sound), AL=1 (play SFX at BX with priority CL),
;           AL=2 (query/stop music), AL=3 (toggle sound).
; ----------------------------------------------------------------------------
snd_api_int03:
    push         bp                                  ; 1000:08c7: 55
    mov          bp, sp                              ; 1000:08c8: 8bec
    ...
```

3. Subsystems classified (182 functions):
   - Video / EGA: Mode 0Dh 320x200 16-color planar rendering, double-buffered page flipping between `A000:0000` and `A000:8000`, 8x8 font blitters, and masked sprite drawers.
   - Audio / PIT: 8253 PIT channel 2 PC speaker sound generation driven by a dual-purpose `INT 08h` timer ISR and controlled via the `INT 03h` API.
   - Input / Keyboard & Joystick: custom non-blocking multi-key `INT 09h` ISR reading port `0x60`, and direct analog game port `0x0201` poller hooked to `INT 15h`.
   - Game engine: sprite state machines, collision detection, item pickups, PackBits RLE level decompressors, and copy-protection ROM checksum verification.

## How to Compile and Run

### 1. Build with Make (Recommended)
```bash
make all      # Automatically extracts data_0.bin if needed, builds both binaries, and validates exact parity
make run      # Boots the assembled comic2.exe directly in DOSBox-X
make verify   # Validates code segment (54,736 B), exe (196,288 B), and all 30 relocation words
```

### 2. Manual Build with NASM
If building manually without `make`, first ensure `data_0.bin` is extracted:
```bash
python3 scripts/extract_data.py
```

### 2. Assemble with NASM
```bash
# Assemble the pure 8086 code segment binary (54,736 bytes):
nasm -f bin comic2_nasm.asm -o comic2_code.bin

# Assemble the complete MS-DOS MZ executable (196,288 bytes):
nasm -f bin comic2_standalone.asm -o comic2.exe
```

### 3. Run in DOSBox-X
You can run the game directly using the included launcher script:
```bash
./run-dosbox.sh
```

Or manually:
```bash
dosbox-x -conf dosbox_deterministic.conf -c "mount c original" -c "c:" -c "comic2.exe"
```
